# Kahoot

Dos juegos, uno por cada sesión.

| Archivo | Uso |
|---|---|
| `kahoot-jueves-22-10.xlsx` | Importar en Kahoot para el jueves |
| `kahoot-jueves-22-10.md` | Guía del presentador con las respuestas correctas y la explicación |
| `kahoot-martes-27-10.xlsx` | Importar en Kahoot para el martes |
| `kahoot-martes-27-10.md` | Guía del presentador |

## Cómo importar

1. Entra a Kahoot y elige Crear, luego Kahoot.
2. Importar preguntas y selecciona el `.xlsx`.
3. Revisa que las 10 preguntas y las respuestas correctas aparezcan bien.
4. Pon un título, por ejemplo Prototipado G3 Jueves.
5. Prueba el juego una vez antes de exponer.

Si el importador falla, la guía `.md` tiene todo el contenido para cargarlo a mano.
